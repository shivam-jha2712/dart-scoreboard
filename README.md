# THROW — V16

Darts scoreboard with:
- 301/501/701/custom scoring
- Individual dart validation
- Exact committed-dart rendering on the board
- Photorealistic board artwork
- Reference-based yellow/red planted darts
- Dart appears only after a score is committed (✓ / Enter / Add round / board click)
- Bust and undo
- Firebase live rooms with anonymous auth

Firebase rules/config are carried forward from the previous build.
